- Added an option to resize spell icons in NPC tooltips.
- Added a setting to show ability details inline or underneath the ability name.
- Added the project icon to the in-game addons page.

- Added descriptive tooltips with white setting-name headers throughout the options panel.

- Improved the options layout by aligning the detail checkboxes and color controls.
