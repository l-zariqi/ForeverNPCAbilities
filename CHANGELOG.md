## Version 1.5.1
- Fixed an issue where ability icon borders would appear when hovering over objects.
- Removed the icon border checkbox and added "None" to the border-style dropdown. Selecting it hides ability icon borders.

## Version 1.5.0
- Added a dropdown to choose the texture used for colored ability icon borders.
- Added clickable previews for each ability icon border texture.
- Added a border style that automatically matches each ability's dispel type, with the regular aura frame as fallback.

## Version 1.4.2
- Added NPC ability data for additional Barrens, Tirisfal Glades, and Riverglades NPCs.
- Tweaked the default ability colors to match the modern UI dispel colors.
- Improved tooltip handling for restricted unit tokens in instanced content.

## Version 1.4.1
- Added support for showing abilities for neutral NPCs, with a separate option to enable or disable them.

## Version 1.4.0
- Added configurable category colours for poison, curse, disease, magic, and physical bleed ability names.
- Added a matching category-coloured border around each ability icon.
- Changed the default ability name colour to yellow and description colour to white.
- Added an optional dispel-type ability detail, separate from spell school.
- Set effect-type ability name colouring to off by default.

## Version 1.3.0
- Added an option to resize spell icons in NPC tooltips.
- Added a setting to show ability details inline or underneath the ability name.
- Added the project icon to the in-game addons page.

## Version 1.2.0
- Added a Hide the "Known abilities" line checkbox to the addon options.

## Version 1.1.0
- Added configurable colors for ability names, descriptions, and details, with a button to restore the original colors.
- Added descriptive tooltips with white setting-name headers throughout the options panel.
- Changed range, cast time, and spell school details to be disabled by default on a fresh install.
- Improved the options layout by aligning the detail checkboxes and color controls.

## Version 1.0.1
- Capitalised modifier keybinds and added more options for ability details.

## Version 1.0.0
- Initial release.
